# 理解卡（understanding-cards）

hai 的自用學習工具：當下用自己的話建立理解、累積成概念卡、考前拿來回想複習。
第一版範圍：心理測驗、心理學實驗法（可自行加科目）。

## 使用
- 直接雙擊 `index.html` 開啟，或在母資料夾用預覽設定 `understanding-cards`（port 8781）。
- 資料存在該瀏覽器的 localStorage。換裝置、清瀏覽器資料前，先在首頁「備份與匯出」存 JSON。
- 注意：用 `file://` 開和用 `localhost:8781` 開，是兩份各自獨立的資料。選一種固定用。

## 設計原則
- 工具不替 hai 寫答案，只協助 hai 自己想、自己說、自己寫。
- 「卡住了」分四步，一次只給一小步：句子開頭 → 換個問法 → 先找例子 → 對照教材。
- 輸入可用打字、語音（zh-TW，需 Chrome／Safari）、手寫畫布（可用 Apple Pencil）。
- 複習先回想、再翻面對照，自評後依狀態排下次複習（1／3／7 天）。
